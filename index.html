Политика конфиденциальности

Приложение «avtohabr» · Обновлено: 4 ноября 2026 года

Настоящая политика описывает, какие данные обрабатываются при использовании приложения «avtohabr» (далее — Приложение), предназначенного для автоматической публикации видеороликов на YouTube-канале владельца Приложения.

1. Какие данные обрабатываются

При входе через Google OAuth Приложение запрашивает разрешение youtube.upload — управление загрузкой видео на ваш YouTube-канал. При этом Приложение получает технический токен доступа (refresh token), который хранится в защищённом хранилище (GitHub Secrets) и используется исключительно для публикации роликов от имени владельца канала.

Приложение не собирает и не хранит личные данные пользователей: имя, email, содержимое канала, статистику, списки подписчиков и иные персональные данные не считываются и не сохраняются.

2. Как используются данные

Токен доступа используется только для одного действия — загрузки видеофайлов и их описаний (название, описание, хэштеги) на YouTube-канал владельца Приложения. Токен не передаётся третьим лицам и не используется для иных целей.

3. Хранение и безопасность

Токен хранится в зашифрованных секретах GitHub (AES-256, среда GitHub Actions). Доступ к секретам имеет только владелец репозитория. Приложение не имеет веб-интерфейса и не принимает данные от внешних пользователей.

4. Отзыв доступа

Владелец канала может в любой момент отозвать разрешение: Google Аккаунт → «Безопасность» → «У приложений с доступом к аккаунту» → удалить «avtohabr». После отзыва публикация роликов прекращается, токен становится недействительным.
